**Photo and Files pipeline**

1. Native Photos now invokes `pick_photos` directly. This is intentional: the shared `api.pickPhotos` override can otherwise open a chooser in the hidden webview. Files invokes the new native plugin command. Replies are validated and picker exceptions propagate with their original reason ([nativeBridgeProtocol.ts:29](/Users/ashtonmiller/DropBeam-ios/src/lib/nativeBridgeProtocol.ts:29)).
2. Rust retries a busy/dismissing/presenting controller for approximately one second, without blocking UIKit. Swift also waits for presentation transitions before opening its Files picker ([ios_media.rs:181](/Users/ashtonmiller/DropBeam-ios/src-tauri/src/ios_media.rs:181), [NativeFolderPicker.swift:6](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/UI/NativeFolderPicker.swift:6)).
3. Photos requests the **current** asset representation, preserving HEIC. It copies the file while the provider URL is valid. Failure falls back to `public.image` data, then `public.jpeg`, writing bytes to a unique temporary directory. Signature detection preserves HEIC/HEIF, PNG, JPEG, GIF, WebP and AVIF extensions. Provider timeout/errors explain iCloud download recovery. `log::info!` records presentation, selected count, each representation, copy success and failures ([ios_media.rs:106](/Users/ashtonmiller/DropBeam-ios/src-tauri/src/ios_media.rs:106), [ios_media.rs:149](/Users/ashtonmiller/DropBeam-ios/src-tauri/src/ios_media.rs:149), [ios_media_format.rs:1](/Users/ashtonmiller/DropBeam-ios/src-tauri/src/ios_media_format.rs:1)).
4. Native `Preparing photo…` / `Preparing files…` overlays include a spinner and Cancel. Cancel removes the pending Swift continuation and ignores its eventual result; it cannot stage chat files, create Send-to state, update an avatar or start an upload. Provider work can finish in the background ([Bridge.swift:175](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/Bridge.swift:175), [Bridge.swift:187](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/Bridge.swift:187), [RootView.swift:48](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/UI/RootView.swift:48)).
Avatar updates reject videos before changing the profile, while preserving HEIC/HEIF image paths (`nativeBridgeProtocol.ts`, `nativeAvatarPath`).

5. Files uses the existing security-scoped, coordinated Swift importer, extended for multiple files and existing native sheets. Copy failures reject the command; partially imported selections are cleaned up ([NativeFolderPicker.swift:26](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/UI/NativeFolderPicker.swift:26), [NativeUIPlugin.swift:55](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/NativeUIPlugin.swift:55)).
6. Chat picks first, receives the native reply, then calls the separate `stageChatFiles` action. Both sides check the conversation identity. Forced state pushes run after replies and on foreground return, so staged chips recover after suspension ([Bridge.swift:169](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/Bridge.swift:169), [nativeBridge.ts:70](/Users/ashtonmiller/DropBeam-ios/src/lib/nativeBridge.ts:70), [nativeBridge.ts:311](/Users/ashtonmiller/DropBeam-ios/src/lib/nativeBridge.ts:311)).
7. Errors reach the native “Couldn’t complete that” alert after waiting for picker dismissal. User cancellation is not reported as an error; no picker exception is converted to an empty selection ([Bridge.swift:125](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/Bridge.swift:125), [RootView.swift:42](/Users/ashtonmiller/DropBeam-ios/src-tauri/plugins/native-ui/ios/Sources/NativeUIPlugin/UI/RootView.swift:42)).
